# 维护记录

更新日期 2026-10-20，当前版本 0.3.10（变速原型）。支持官谱和自制谱，用户已确认此前自制谱可用。修复摘要统一见 [CHANGELOG](../CHANGELOG.md)，此处记录继续维护所需信息。

## 入口和基线

- 源码 `src`；发布 `releases/0.3.10`；版本与校验值 `maintenance-state.json`；本版检查见 [0.3.10 验证](0.3.10验证.md)，历史迁移检查见 [仓库验证](仓库验证.md)。
- 基线为 Muse Dash 6.7.0、Unity 2019.4.41f1、MelonLoader 0.7.0、Windows x64 IL2CPP、.NET SDK 6.0.424。
- 游戏目录通过 `-GameRoot` 或环境变量 `MUSEDASH_GAME_ROOT` 传入。仓库中不保存用户专属的默认安装路径。
- `main` 为维护分支；0.3.9～0.3.10 开发分支为 `feature/playback-speed`，基于 0.3.8 的 `feature/range-presets`。`v0.2.1`～`v0.3.7` 是迁移时生成的原版本快照标签，包含各版原 DLL 和源码；历史发布和备份保留。
- 用户补充核对：CustomAlbums 将 BMS 转换为游戏原生 StageInfo/MusicData，核心运行框架共用。`album_…` 是资源名，当前曲目 UID 为 `999-序号`。现存三处前缀条件保留原样，不作为识别自制谱的依据；预设从已加载的原生数据建立指纹。

## 功能约定

- 练习保护与循环运行是独立状态。初始 A=0、B 未设，启用练习、进入新谱面不自动跳转。
- F7 标 A，清除 B 和待执行回跳并停止旧循环，继续播放；F8 标 B，区间有效后开始循环。
- F9 开始／重启；A、B 或提前时间缺失、无效时通过游戏原生暂停流程暂停，停止旧循环。暂停中 F9、Resume marking、退出谱面仍可用。
- B 至少比 A 晚 1 秒；Lead-in 默认 3 秒，允许 0 和小数；跳转位置 `max(0, A - Lead-in)`。当前输入草稿不自动保存，命名预设按用户操作保存到本地 JSON。
- 开启练习且谱面数据就绪后读取预设列表；进入谱面仍 A=0/B 未设，选择预设停止旧循环并只填入参数，F9 开始。不在每轮回跳时写盘。
- 名称输入仅暂停时可编辑；预设写入采用临时文件加原子替换，保留上一份 .bak。损坏主文件只读恢复，未知格式保持原样。谱面内容变化只提供待确认的复制，不覆盖旧记录。
- 优先场景内回跳，恢复失败时完整重载。内部重载保留当前运行区间，外部打开新谱面重置为 A=0、B 未设。
- 启用练习期间拦截 5 处 Fever 入口，结束已有 Fever；不修改自动 Fever 偏好。
- 7 处成绩保护入口阻断保存／上传；启用练习后本进程持续阻断，正常记分须重启游戏。
- 游戏内测试由用户完成，维护时不要自动启动或接管游戏。

## 构建、检查和发布

1. 每次开发新功能前，先创建并切换到新的独立功能分支（如 `feature/功能名称`）。修改运行时代码前，保存实际安装 DLL、源码和需要的诊断日志。
2. 修改 `src` 并同步版本声明；运行 `scripts/Build.ps1` 和适当检查。`scripts/Test.ps1` 默认先构建，再运行输入路由、区间控制、预设存储回归、四项编译后及原生审计及安装脚本隔离验证，审计明确读取本次构建 DLL。
3. 依赖来自本机游戏的 `MelonLoader/Il2CppAssemblies`、`MelonLoader/net6`。原生审计另读 Cpp2IL dummy 程序集；NuGet.Config 清空外部包源。
4. 发布产物复制到新的 `releases/版本`，更新说明、校验值及验证状态。不要覆盖旧发布 DLL 或改写历史标签。
5. 关闭游戏后仅替换本练习 DLL，记录实际旧／新哈希；用户自行游戏内验证。游戏升级后先复核指纹和原生结构。

变速实现位于 PlaybackClock／PlaybackSpeed，预设面板位于速度面板下方。原有状态恢复、输入、区间和预设存储逻辑保持不变。构建路径会影响编译产物哈希，发布后以 `maintenance-state.json` 记录为准。构建和分析输出位于忽略的 `artifacts`。

## 排查和分析

- 日志为游戏目录 `UserData/MuseDashPracticePrototype/diagnostics.ndjson`，每次启动覆盖；排查前保存。
- 常见事件：`setup_error`、`runtime_error`、`note_baseline_error`、`input_routes_reset`、`fast_rewind`、`reload_fallback`、`parameters_paused`。
- 预设事件：`preset_chart`、`preset_saved`、`preset_selected`、`preset_error`、`preset_file_warnings`。存储格式及恢复方法见 [区间预设](区间预设.md)。
- Mono.Cecil：`MelonLoader/net6/Mono.Cecil.dll`；代理程序集：`MelonLoader/Il2CppAssemblies/Assembly-CSharp.dll`；原生 dummy：`MelonLoader/Dependencies/Il2CppAssemblyGenerator/Cpp2IL/cpp2il_out/Assembly-CSharp.dll`。
- 便携分析入口见 [tools/analysis](../tools/analysis/README.md)。保留了原生目标 RVA/Length、符号及相关字段资料；以 exact Length 为准，不用相邻符号距离估算方法长度。
- 原工作区保留完整分析输出、个人日志和备份，仓库只纳入继续维护需要的工具与元数据，不纳入第三方反编译代码或游戏二进制。

静态检查不能替代游戏内验证。历史修复记录也不代表所有组合已在游戏内验证。

变速约定：0.50～1.25 倍，音高随速变化。暂停或选曲时设置后 Apply，不自动写盘。A/B/Lead-in 保留原歌曲坐标；当前只映射歌曲 Stopwatch 的 ElapsedTicks，其他 Stopwatch 不变。Spine 无参 Update 使用 GlobalTimer 的独立墙钟；活动练习谱面将其 deltaTime 同倍率缩放，暂停／菜单不缩放，显式 Update(float) 不另加倍率。不要通过改写音符判定时间或补偿音频偏移来修正动画速度。回跳重设锚点，暂停、退出和异常恢复全局时间设置。详见 [变速练习](变速练习.md)。
