# Muse Dash A–B 练习 0.3.9

适用本机 Muse Dash 6.7.0、MelonLoader 0.7.0、Windows x64 IL2CPP。

支持官谱和自制谱；用户已确认当前自制谱可用。安装方式见 [安装说明](安装说明.md)。

## 启用与开始循环

初始 A 为 0，B 留空，提前时间仍默认为 3 秒。

1. 点击 `Enable practice` 开启练习保护。此时禁用 Fever，但不开始循环、不跳转歌曲。
2. 打开谱面，歌曲正常播放。每次进入新谱面都将 A 重置为 0、B 留空，等待标记。
3. 按 F7 设置 A，再按 F8 设置 B，会自动从 A 前的提前位置开始练习。也可保留默认 A=0，只按 F8 标记 B。
4. 若手动填写面板中的 A、B、Lead-in，按 F9 或点击 `Start / restart [F9]` 开始循环。
5. 循环中再按 F7，会清除旧 B 并停止旧循环，歌曲继续播放，等待新 B。

F6 显示／隐藏面板。A、B、Lead-in 均以秒为单位，使用小数点；B 至少比 A 晚 1 秒，Lead-in 不能为负，支持 0 和小数。回跳目标为 `max(0, A - Lead-in)`。

## 命名区间预设

开启练习并打开谱面后，下方 `Saved ranges` 自动读取该曲目难度的预设。`Save new` 保存当前参数，`Pause to edit name` 暂停后可输入名称，`Update` 更新或改名；`Delete` 需再次确认。

点击当前预设只填入参数并停止旧循环，不自动播放或回跳，按 F9 开始。谱面变化后的 `[other revision]` 项需通过 `Copy here`、`Confirm copy` 明确复制；原记录保留。文件、备份及分享方式见 [区间预设](区间预设.md)。

## 参数未设时的 F9

A、B、Lead-in 任意一项缺失或无效，按 F9 会撤销待执行回跳、停止循环，并使用游戏自身的暂停流程同步暂停歌曲、计时器和动画，显示面板及参数提示。

- 填好参数后再按 F9，可恢复并开始循环。
- 若要继续听歌选择 B，点击 `Resume marking` 恢复正常播放，再按 F7／F8 标记。
- 暂停中仍可使用 `Exit practice chart` 退出谱面。

## Fever

练习启用期间禁用自动和手动 Fever 触发；若开启练习时已经处于 Fever，则结束当前 Fever。没有改写游戏的自动 Fever 偏好或其他保存设置。离开练习后，触发拦截解除。

练习启用后仍拦截本进程的成绩保存和上传；恢复正常记分需完全退出并重新启动游戏。

## 自行验证

本版的构建及检查状态见 [0.3.9 验证](0.3.9验证.md)。游戏内效果由用户验证，维护时未启动游戏。

1. 确认刚启动时 A=0、B 为空；开启练习并打开谱面，观察歌曲不会立即跳转或循环。
2. 保持自动 Fever 设置开启，练习中打满能量，确认 Fever 不会触发；也可在已有 Fever 时开启练习，检查效果结束。
3. 按 F7、F8 选段，检查标好 B 后自动开始；循环中 F7 可继续取消旧 B。
4. 清空 B 后按 F9，检查游戏暂停；填好 B 再按 F9，检查开始循环。
5. 清空 A 或 Lead-in 后重复上述检查；再试 `Resume marking`，确认能继续播放选段。
6. 从一张谱面退出并打开另一张，检查再次等待标记，A=0、B 留空。长条、连打、角色和输入修复应维持原有效果。
7. 保存两个命名区间，退出并重新打开同一谱面，确认列表保留且没有自动循环。选择一项后再按 F9，检查参数及循环范围。
8. 检查改名／更新、确认删除、不同难度隔离和自制谱；可先备份文件，再尝试复制分享、损坏主文件读取 .bak，以及旧谱面版本的确认复制。

此前的物件、长条材质／动效、角色状态、输入去重和连打恢复代码保留。面板输入草稿不自动保存，命名预设通过明确保存操作持久化。

## 日志与回退

诊断日志位于游戏目录 `UserData/MuseDashPracticePrototype/diagnostics.ndjson`，每次启动覆盖。新增 `practice_enabled`、`fever_guards`、`parameters_paused`、`marking_resumed`；`stage_started` 记录是否循环及是否计划跳转。

历史发布与备份保留。0.3.9 开发前另有 0.3.7 源码、实际 DLL 和日志备份；位置见版本验证记录。安装脚本的备份与回退方法见 [安装说明](安装说明.md)。预设 JSON 备份独立于 DLL 回退。

仓库 `scripts/Build.ps1` 用于编译，`scripts/Test.ps1` 运行检查。`tests/RangeControls` 检查区间状态。命令文件新增 `enable` 操作只启用练习；`arm`／`restart` 对应 F9 的开始／参数暂停行为。

## 变速原型

新增 Speed 面板，支持 0.50～1.25 倍随速变调。暂停后设置并 Apply，F9 重启区间或 Resume marking 继续。A/B/提前时间使用原歌曲秒数，倍率不写入预设。操作和限制见 [变速练习](变速练习.md)。
