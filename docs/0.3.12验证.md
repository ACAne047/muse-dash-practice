## 实现约定

每次实际 seek 设置一次 `[target, A)` 窗口；按原歌曲时间查询，暂停冻结、变速跟随。窗口到 A 后被消费，F7、参数暂停、重新开始、退出、换谱和卸载清理。A=0 或零提前时间不额外保护。仅在练习已启用、当前谱面和运行区间内拦截当前角色的 Hurt、MissHardEffect 及负向 AddHp，保留回血及音符判定，不写角色长期无敌标志。

回跳规划保留 `showTick <= target` 的生成游标，同时找出原生 missTick／持续时间／长条尾仍跨越 target 的物件。复用 `GetPreLoadGameObject → CreateBattleEnemy → CreateObj → ObjInit → Node.Run` 正常出场路径，不重新调用控制器 Init，不追加输入路由；创建后在 finally 恢复三处游标。时间仍冻结在目标位置时补出场，使原生位置及动画按歌曲时间定位。未来 show 事件及完全过期的物件不提前激活。此前的快照、长条动效、连打回调清理、输入去重和变速校准逻辑继续保留。

原生依据：Hurt RVA `0x214C600`、AddHp `0x214AA40`、CreateBattleEnemy `0x21495A0`、ObjInit `0x214A0C0`、Node.Run `0x206B100`。GetMusicIndexByGenTick（`0x4958B0`）使用精确 showTick 和生成游标；目标点恰好等于出场 tick 时也应补出场并跳过旧事件。地址及 Length 见 `tools/analysis/metadata/rewind-boundary-native-targets.json`，仅适用于维护基线 GameAssembly。
