# 0.3.8：区间预设

在 `feature/range-presets` 开发。新增本地命名区间的保存、更新、删除及列表选择；支持稳定数据指纹匹配、跨谱面版本确认复制、JSON 原子写入和只读备份恢复。此前的回跳、物件恢复、Fever 和成绩保护行为保留。

开启练习、进入谱面后，在面板下方 `Saved ranges` 操作。选择预设只填入参数、停止旧循环，仍需 F9 开始；名称在暂停时编辑。个人数据保存在游戏 `UserData/MuseDashPracticePrototype/presets`。
